这个章节将由三个进阶ai项目组成,需要提前创建虚拟环境和一些库,你可以使用我们提供的一键安装脚本来创建venv虚拟环境和依赖的pip包

部分一:opencv
---------------------

1.ESP-IDF+Opencv实现图像采集与轮廓处理
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
首先需要烧录IDF章节的usb_webcam项目的摄像头bin文件到开发板,将摄像头的图像通过UVC协议传输到电脑上,电脑端使用openCV实现物体轮廓识别。

接下来打开vscode,打开advance文件夹,选择1.opencv_capture目录,然后点击openCV.py

注意: 在运行之前,你需要先安装opencv2的库

    1.首先创建虚拟环境,并进入虚拟环境(这个是为了不影响系统的python环境)

    2.使用pip按照opencv2的库

    3.将摄像头连接到电脑上,打开自带的相机软件,确保摄像头可以正常工作

    4.运行openCV.py,你将看到摄像头采集的图像,并且在图像上会有一个绿色的矩形框,opencv2会给物品边缘轮廓描边
